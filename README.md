## Sobre o Projeto

Este é um portfólio pessoal desenvolvido como uma landing page de página única, projetada para apresentar minhas habilidades, projetos e experiências profissionais como desenvolvedor full stack e engenheiro da computação. ## Como Executar o Projeto

1. Clone o repositório:
   ```
   git clone <url-do-repositorio>
   ```

2. Instale as dependências:
   ```
   npm install
   ```

3. Execute o servidor de desenvolvimento:
   ```
   npm run dev
   ```

4. Abra o navegador e acesse `http://localhost:5173` (ou a porta indicada no terminal).

Para build de produção:
```
npm run build
```

Para preview da build:
```
npm run preview
```
